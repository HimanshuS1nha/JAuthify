# JAuthify

JAuthify is a secure authentication platform built with organization-based architecture, enabling seamless user management, role-based access control, and scalable multi-tenant authentication.

## Get started

1. Server
   - Copy application.properties.example as application.properties and add all the required values
   - Run the server

   ```bash
   ./mvnw springboot:run
   ```

2. Client
   - Copy .env.example as .env and add all the required values
   - Install dependencies

   ```bash
   npm install
   ```

   - Run the server

   ```bash
   npm run dev
   ```

## Features

- Email password auth flow
- OTP based email verification
- Multiple login sessions
- Organization architecture with members and invitations
- Role based access control

## TECH STACK USED

- Spring Boot
- Spring Security
- React
- Tailwind CSS
- ShadCn UI
